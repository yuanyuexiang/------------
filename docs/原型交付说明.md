# Jinbang（金榜）原型交付说明

**日期**：2026-08-22　**范围**：《原型开发计划》S1–S5 全部主线功能　**状态**：可演示、可验收

## 1. 一句话

对真实国网招标文件包（江苏服务/陕西物资/福建竞谈）跑通"导入 → 解析 → 确认 → 资格自检 → 生成商务/技术文件 → 合规审查 → 模拟评分 → 递交矩阵 → 导出"的完整闭环；50 项自动化回归全绿，20 处预埋否决错误拦截率 100%。

## 2. 怎么看（5 分钟）

```bash
pip install -e ".[dev]"          # 首次
python scripts/import_profiles.py  # 导入测试企业A（南京百恩特）档案
python scripts/demo.py           # 端到端（1 秒，不用 LLM）
python scripts/demo.py --llm     # 含 LLM 起草/评分/业绩匹配（约 5 分钟，需 .env）
pytest -q                        # 50 项回归（含 21 处错误注入拦截）
```

Web 工作台：`uvicorn jb_api.main:app --port 8000` + `cd apps/jb-web && npm run dev` → http://localhost:5173
（项目列表 → 确认 TRM → 资格自检 → 生成与审查工作台 → 档案编辑）。Docker：`docker compose up -d --build`。

## 5. 如实说明：未完成 / 未验证

- **golden 标注集**未建（需业务专家）——准确率是估计值，非实测。
- **PostgreSQL / Celery / gotenberg 真实运行**未验证（本机无 Docker 守护进程）；代码与 compose 配置已就位，需 `docker compose up` 跑一次。
- **知识库仍是整体 JSON**（profiles 表），未拆多表；字段级检索与有效期预警靠应用层扫描。
- **检索层为进程内 BM25**，pgvector 混合检索未接（接口已留）。
- **投标工具 U+ 编辑内页**字段级对接未做（等截图）。
- 评分模板库按包引用：江苏包只给模板名，demo 用福建包内的 6 套官方模板补齐——正式系统需维护全局模板库。
- 前端未做在线编辑；修改走"下载 Word 改 → 重新上传档案/重跑"。
