# WPS 排版与验收

本项目以实际使用的 WPS Office 版本作为最终排版验收环境，LibreOffice/Gotenberg 的 PDF 仅作辅助检查。

## 生成规则

- 采购规定的表格、段落及分节优先保留。填空定位到实际变化字符，保留其余 run 的字体、加粗、下划线和字号。
- 新生成副本不继承采购母版的“仅批注”等编辑限制，确保 WPS 可编辑、更新目录。采购原件保持原状。
- 系统目录采用原生 TOC 域，缓存保留标题链接及 PAGEREF 页码；在 WPS 中可“更新整个目录”。原有非系统目录不自动改写。
- 本次团队表只包含姓名、岗位、可投入状态及证明材料索引，重复表头、固定列比例且简短行不跨页。长篇内部资料路径与经历核对意见保留在企业资料中。
- 末尾仅在空分节且页形相同时合并普通另起页；保留真实正文分节、奇偶页要求、签章文字及留白。
- 缺项提示及团队资格集中核对仍保留，排版修复不会自动改变资格结论或绕过正式导出检查。

## WPS 复核

1. 打开生成的副本，确认没有因继承采购母版保护而导致的“编辑受限”。
2. 在目录内点击后，选择“引用 → 更新目录 → 更新整个目录”，检查新增标题、层级和页码。
3. 查看封面、目录、主要表格、长技术响应、图片附件、团队安排及末页签章区域。
4. 检查文字截断、异常窄列、越界图片、异常空白页、跨页断行和缺字；保留采购要求的签章留白。
5. 使用 WPS 本地输出 PDF，核对页数及关键页面；记录 WPS 版本、字体环境和文件哈希。

## 字体部署

Gotenberg 基础镜像已固定到本次环境的 digest，避免可变标签使转换结果悄悄变化。
授权字体可放入 `deploy/fonts/`，然后重新构建转换器；字体文件被 Git 忽略。
使用 `.venv/bin/python scripts/check_document_fonts.py 文件.docx` 可只读核对字体声明与转换器字体清单。

报告包括未使用的备用样式，缺失声明是排查线索，不等于全部都影响正文；主题字体及 WPS 字体替代仍须实测。
未提供完整授权字体时，不能宣称转换器与 WPS 字体一致。不要仅为消除字体提示而全局替换采购指定字体。
