# 国网物资与服务投标 · 智能写标书 Agent 场景细化方案（v0.1）

> 本文是《智能写标书Agent技术方案》的行业落地篇：把通用方案落到**国家电网（含总部集中招标、各省公司招标、协议库存）的物资类与服务类招标采购**上。凡与通用方案重复的架构内容不再赘述，只写国网场景带来的差异、约束与细化设计。
>
> 说明：国网招标文件每个批次都有差异，以下“典型结构/典型评分”来自公开招标公告、投标提示、评分细则及 ECP 操作手册的梳理，落地时以**当批次招标文件**为唯一真源（这正是系统“招标文件解析”模块存在的意义）。

---

## 1. 为什么国网是一个“好切入”的场景

1. **高度标准化**：国网招标文件模板、技术规范书（物资采购标准）、评标细则、投标工具全集团统一，批次之间差异主要在“专用部分”和分包清单——模板驱动的 Agent 最擅长这种“结构固定、内容变化”的写作。
2. **高频高量**：总部每年数十批次、每批次几十到上百个包；省公司、协议库存、服务类框架招标更多。供应商一年投几十上百个包，写标书是持续性工作，不是偶发任务。
3. **规则严、否决多**：技术参数响应表一处“以完全响应代替具体应答”即可能否决；资质业绩、不良行为、绩效评价都有硬规则——这些恰恰是规则引擎和结构化知识库能兜住的。
4. **电子化彻底**：ECP2.0 全流程电子投标，输入（招标文件）和输出（投标文件各部分）的格式都是确定的，便于系统对接。

## 2. 国网招标采购业务画像

### 2.1 采购组织与平台

| 要素 | 说明 |
|---|---|
| 平台 | 国家电网新一代电子商务平台 ECP2.0（ecp.sgcc.com.cn）— 电工交易专区；国网物资业务运营服务平台 BOSP2.0（获取采购文件）；供应商关系管理 SRM（注册、资质能力信息库、绩效、不良行为） |
| 招标人/代理 | 总部集中招标：招标人国家电网有限公司，代理国网物资有限公司；省级：各省电力公司 / 省物资公司 / 委托代理 |
| 采购类型 | **物资类**（输变电项目变电/线路设备、配网物资、营销计量设备、信息通信设备、特高压材料等）；**服务类**（设计、监理、咨询、信息化开发运维、检测、培训、物业后勤等）；工程类（施工，本篇不展开） |
| 采购方式 | 公开招标（资格预审 / 资格后审）、邀请招标、竞争性谈判、竞争性磋商、授权框架、协议库存（中标后按需下单） |
| 批次与分包 | 以“批次”组织（如“国家电网有限公司 2026 年第 X 批采购（XX 项目第 X 次 XX 设备招标采购）”），批次下按物料类别/电压等级/供货区域划分**标包**；一个供应商可投多个包，每个包独立制作、独立评审 |
| 投标工具 | “供应商投标工具 U+”（ECP 下载专区）：导入 SGCC 招标文件 → 按包编制商务/技术/价格文件 → CA 数字证书签章加密 → 上传；超容量用“商务技术大文件”功能 |
| 开评标 | 网上开标、在线解密、评标在国网内部局域网进行；澄清通过 ECP 在线答复；中标候选人在 ECP 公示 |

### 2.2 国网招标文件的典型结构

```
第一章  招标公告 / 投标邀请书（含分包一览表、资格要求摘要）
第二章  投标人须知（含前附表：时间节点、保证金、电子投标要求、澄清方式、否决条款）
第三章  评标办法（资格审查 / 符合性审查 / 商务评审 / 技术评审 / 价格评审 + 评分细则）
第四章  合同条款及格式（物资：供货合同；服务：服务合同 / 框架协议）
第五章  供货要求 / 技术规范书（物资：通用技术规范 + 专用技术规范 + 技术参数响应表；服务：服务需求书 / 技术要求）
第六章  投标文件格式（商务部分、技术部分、价格部分各表格模板）
附件    分包清单、物料清单、投标提示、资质业绩要求表
```

### 2.3 投标文件典型构成（按包）

**商务部分（docx，由投标工具按包上传）**

- 投标函及附录、法定代表人身份证明、授权委托书
- 投标保证金（国网多为电子保函/电汇，不接受纸质）
- 资格审查资料：营业执照、资质/许可证、财务审计报告、纳税/社保、信用承诺、无不良行为声明
- **资质业绩文件**：通过投标工具“资质业绩模块”上传并生成**凭证单**（未提供凭证单的申请人被否决）；通过国网**资质能力信息核实**的供应商可凭“一纸证明”（核实结果）减少重复提交
- 供货/服务业绩一览表（国网内业绩可在平台业绩库核验）
- 商务偏差表、售后服务承诺、供货/服务周期承诺、质量保证承诺
- 联合体协议、分包说明（如允许）

**技术部分（docx/pdf）**

- 物资类：
  - **技术参数响应表**（专用技术规范中的“招标人要求值 / 投标人响应值”逐条填写，不得以“完全响应”替代具体数值）
  - **技术偏差表**（无偏差也要填“无偏差”）
  - 型式试验报告 / 检测报告（国家认可检测机构出具；投标时满足资质业绩要求，供货时承诺提供委托试验报告）
  - 产品技术方案/技术说明、主要原材料与元器件清单及供应商、生产设备与检测设备清单、工艺流程与质量控制、产能与供货计划、包装运输与现场服务方案、绿色/自主可控说明
- 服务类：
  - 项目理解与需求分析、总体技术/服务方案、实施组织与进度计划、项目团队与人员配置（简历、证书）、质量保证体系、信息安全与保密措施、运维/售后与培训方案、验收与考核响应、风险与应急预案、技术偏差表

**价格部分（在投标工具内填报 + 生成）**

- 开标一览表、分项报价表（按包、按物料行项目：单价/数量/合价/税率）、报价说明
- 协议库存：投单价，按预估量算总价；服务类：按人天/工作量或总价

### 2.4 评审规则的国网特点

| 环节 | 国网特点（典型） | 对系统的要求 |
|---|---|---|
| 资格审查 | 资质、供货/服务业绩（近 N 年、电压等级/类别/金额）、财务、不良行为处理状态、资质能力核实结果 | 企业库要按国网口径记录业绩（物料类别、电压等级、合同额、国网内/外）；不良行为/绩效状态要能录入与预警 |
| 符合性审查 | 投标函/授权书签章、保证金、投标有效期、技术参数响应表完整性、★条款、凭证单 | 否决规则库国网版 |
| 技术评审 | 业绩水平、资源实力（创新、工艺、原材料、自主可控、工装/检测设备）、质量控制（体系、MES 等）、投标响应、绩效评价、质量问题扣分（抽检不合格） | 技术部分要“对着评分项写”，且需要结构化证据（专利/标准/设备清单/体系证书） |
| 商务评审 | 履约能力（经营状况、售后、应急保供）、高质量发展评价（绿色、管理体系、创新成果、研发团队、研发投入、高新、数智化）、投标响应（报价质量）、诚信评价（不良行为、失信、环保处罚扣分） | 企业库需新增“高质量发展评价”维度的证据材料 |
| 价格评审 | 评标基准价（有效报价均值下浮 / 最低价等）+ 偏离率扣分；协议库存按单价 | 价格分公式解析 + 模拟 |
| 其他 | 投标人应**自行编制**投标文件，不得委托中介或中间人；同一批次内多包响应内容雷同检查；供应商绩效评价、不良行为公示 | 系统只能作为供应商**自用工具**部署；多包内容差异化；元数据清理 |

### 2.5 国网场景常见否决/扣分点

1. 技术参数响应表：响应值不满足要求值；未填写响应值；以“完全响应/满足”代替具体数值；响应值与型式试验报告不一致
2. 资质业绩文件未通过投标工具生成凭证单；业绩不在要求的时间/类别/电压等级范围；业绩证明材料不全（合同关键页、验收/投运证明）
3. 型式试验报告过期、型号与投标产品不一致、检测机构不被认可
4. 不良行为处理期内、失信被执行、环保处罚未披露
5. 多包投标文件内容完全一致且与包专用要求不符；复制历史标书未改批次/包号/物料名称
6. 商务/技术文件格式与第六章不符、缺页、签章缺失；大文件未按要求加密提交；上传超时
7. 报价超出限价、分项报价与开标一览表不一致、税率错误（货物 13%）、货币单位“万元/元”混淆、小数点错位
8. 报价超限（超过其余投标人均价一定百分比，按品类 5%–10%）、不平衡报价（同固化规范 ID 同物资描述的行项目单价偏离自身均值 ±12%）
9. 非结构化技术规范（ID 非 9999）未以附件形式逐项响应；型式试验报告未覆盖包内最严物料参数或有效期未覆盖开标日
10. 保证金未按包附明细表、未从基本户转出；凭证单未以压缩包原样上传或分标不对应
（逐条规则与来源见第 8 节“国网否决规则库 v0.1”）

解析要点：

- **按包拆解**：分包清单、每包的技术规范专用部分、资格要求、限价都要落到 package 级；同批次多包共享通用部分。
- **技术参数响应表结构化**：从第五章专用部分把“序号/项目/单位/招标人要求值”逐行抽出，形成可填写的表格对象，★/▲ 标记保留。这是物资类最关键的一步，必须表格级保真（docx 表格直接解析，PDF 走版面分析）。
- **物资采购标准对照**：国网技术规范多来自统一的“物资采购标准”，系统可维护**技术规范 ID → 历史响应表**索引，新批次先按规范 ID 匹配历史响应，再与本批次差异比对。
- **国网评分细则模板化**：国网技术/商务评分项相对固定（业绩水平、资源实力、质量控制、高质量发展评价、诚信评价……），预置评分项字典，解析时做匹配 + 差异提示，提高准确率。

### 3.2 企业知识库 → 国网供应商专属数据

在通用知识库之上增加：

| 数据域 | 内容 | 用途 |
|---|---|---|
| 国网供应商档案 | ECP/SRM 注册信息、供应商编码、资质能力核实结果（“一纸证明”及覆盖物料类别、有效期）、绩效评价得分、不良行为处理记录及解除日期 | 资格自检、商务评分预测、风险预警 |
| 物料与产品库 | 按国网物料类别/物料编码组织的产品型号、参数表、型式试验报告（机构、日期、型号、有效性）、检测报告、自主可控说明 | 技术参数响应表自动填写、报告匹配 |
| 技术规范响应库 | 技术规范 ID → 历史“技术参数响应表/技术偏差表”及其投标结果 | 同规范复用、差异提示 |
| 业绩库（国网口径） | 项目、包、物料类别、电压等级、数量、合同额、签约/投运时间、国网内/外、证明材料 | 资格条件与“业绩水平”评分匹配 |
| 生产/检测能力 | 生产设备清单、检测设备清单、工艺文件、MES/ERP 等系统证明、产能数据 | 资源实力/质量控制评分章节 |
| 高质量发展证据 | 绿色发展规划、ISO 9001/14001/45001/50001 等体系证书、环评/能评/ESG 报告、绿电绿证、创新成果（国家级/省级）、研发团队人数、研发投入占比、高新技术企业证书、数字化标杆认定 | 商务评分“高质量发展评价” |
| 标准/专利/论文 | 参与制定的国标/行标/团标/企标、专利、核心期刊论文（第一单位）、科技奖励 | 技术评分“创新能力” |
| 服务类能力 | 项目团队人员（职称、证书、国网项目经历）、服务方案素材、信息安全资质（等保/ISO 27001）、驻场/响应承诺话术 | 服务类技术部分 |

运营要求：型式试验报告、体系证书、资质能力核实结果、不良行为解除日期都有**有效期/时效**，必须预警；绩效评价与抽检结果按季度更新。

### 3.3 Agent 编排 → 国网专用逻辑

**资格自检 Agent（国网版）**
- 按包比对：资质、业绩（类别/电压/数量/年限）、财务、资质能力核实覆盖范围、不良行为状态
- 输出“每包可投性矩阵”：可投 / 有风险 / 不可投 + 原因 + 补救（如补充型式试验报告）
- 协议库存批次：提示历史中标单价、预估量

**Planner（国网版）**
- 多包策略：按包生成写作计划；识别“通用部分可共享、专用部分必须差异化”的章节，避免多包雷同
- 自动生成待办：需人工决策项（报价、供货周期、是否投联合体）

**商务部分 Agent（国网版）**
- 按第六章格式填投标函/授权书等；自动挂接凭证单所需的资质业绩文件清单（提示在投标工具中生成凭证单）
- 高质量发展评价材料组装：按评分项逐项挑选证据并生成“评分项 ↔ 材料页码”对照表
- 诚信声明：根据不良行为库状态生成如实披露文本（系统禁止隐瞒，只做提醒）

**技术部分 Agent（国网版 · 物资）**
- **技术参数响应表自动填写**：每行从产品库取实际参数值，写“具体数值/型号”，不写“满足/完全响应”；响应值 < 要求值时标红并生成偏差；与型式试验报告数据交叉校验
- **技术偏差表**：逐条生成，无偏差时按国网格式填“无偏差”
- 技术方案章节按评分项组织：业绩水平 → 资源实力（创新能力/工艺/原材料/自主可控/工装检测设备）→ 质量控制 → 投标响应 → 绿色评价；每节引用结构化证据
- 报告匹配：按投标型号匹配型式试验/检测报告，检查型号、日期、机构、覆盖参数

**技术部分 Agent（国网版 · 服务）**
- 以服务需求书为纲：逐条需求 → 响应方案；生成需求响应对照表
- 项目团队：从人员库按要求（职称、证书、国网项目经验）推荐人选并生成简历表
- 信息安全、保密、驻场响应等国网常见要求使用审核过的话术库

**价格部分 Agent（国网版）**
- 按包/物料行项目生成分项报价表（含税率），校验合价、开标一览表一致性、限价
- 基准价模拟：解析本批次价格评审公式，结合历史中标价区间模拟价格分
- 输出供人工在投标工具中填报的“价格填报清单”（价格在工具内填，系统不替代工具）

**合规审查 Agent（国网版）** —— 在通用清单上叠加国网专项：
- 技术参数响应表：空值 / “完全响应”类措辞 / 响应值不满足 / 与报告不一致
- 资质业绩凭证单提示、型式试验报告有效性、核实结果覆盖范围
- 多包雷同检测：同批次各包技术部分相似度，专用部分是否差异化
- 批次/包号/物料名称一致性（防止复制历史标书）
- 不良行为/失信/环保处罚如实披露检查
- 文件格式：商务 docx、技术 docx/pdf、大小限制、命名规则（按工具要求）
- 元数据清理、暗标（如有）

**模拟评分 Agent（国网版）**
- 预置国网技术/商务评分项字典，逐项打分，输出预估分与“缺证据”清单（如“研发团队 ≥30 人可得 6 分，当前证据显示 22 人”）

### 3.4 文档引擎 → 投标工具 U+ 对接

- 输出物：每个包一套 **商务部分.docx、技术部分.docx/.pdf、价格填报清单.xlsx**（及附件图片），命名按工具要求
- 母版：直接用第六章“投标文件格式”中的表格做模板填充，保留国网表格样式
- 技术参数响应表、技术偏差表、商务偏差表以 docx 表格原样输出
- 大文件策略：技术部分含大量扫描件时自动拆分“主文件 + 附件卷”，提示用“商务技术大文件”通道
- **最后一公里仍由人在投标工具中完成**：导入文件、资质业绩模块生成凭证单、价格填报、CA 签章加密、上传、开标解密。系统提供“投标工具操作清单”（按包 checklist）与倒计时提醒
- 预留：若后续国网开放 API 或工具支持批量导入，再做深度集成

## 6. 合规与定位（国网特有）

1. **自用工具定位**：国网投标提示明确“投标人应自行编制投标文件，不得委托中介机构或中间人”。系统必须以**供应商自有工具**形式私有化部署或专属租户部署，由供应商员工操作；产品不得以“代写标书服务”形式向国网项目提供，多租户时禁止同一批次同一包为多家投标人生成文件。
2. **如实披露**：不良行为、失信、处罚信息系统只做提示与文本生成，不提供隐瞒选项。
3. **数据边界**：招标文件、技术规范可在企业内部复用；不得把其他投标人信息、国网未公开信息入库。
4. **元数据与雷同**：导出文件清理属性，多包差异化，避免被判串标/雷同。

### 8.5 仍需真实招标文件才能校准的项（2026-08 已回填）

> 本节所列缺口已基本补齐：工作区 `物资/`、`服务/` 目录现有 4 套真实招标文件包（陕西物资集招 30+ 分标、信通中心物资、江苏服务公开招标、福建服务竞谈）及真实投标文件成品。逐项分析见《国网真实招标文件结构分析.md》，要点：

- ✅ 第六章"投标文件格式"精确版式：已获得（含官方"提交方式表"= 递交矩阵原版，注明每份文件的投标工具上传端口）。**制作粒度实测为：价格按包、商务按分标、技术按包**。
- ✅ 评标办法前附表条款号体系：已获得（否决情形表 46 行全文、价格分公式族 5 种变体、基准价浮动系数开标现场随机抽取、低于成本认定 50%/45% 规则、同一分标限中 1 包）。
- ✅ 服务类评分细则：已获得官方评分模板 xlsx（商务 FWSW01；技术按业务线 18 种模板，如 JS-FWTY 通用、JS-ZHFW01 科技项目），评分项字典可直接照抄。
- ✅ 技术规范书结构：三段式（标准技术参数表[项目需求值/投标人保证值]、项目需求部分、投标人响应部分 3.1–3.7 表格），系统自动填写目标明确。
- ✅ 投标工具 U+ 主界面：已由实机截图确认（v1.0.0.18）——左侧导入招标文件包建项目，主区四通道（商务/价格/**资质业绩**/技术）按标段挂文件，按钮流 编辑→生成→查看编辑→导出查看→加密提交→撤回；详见《国网真实招标文件结构分析.md》§8。仅剩各通道编辑内页表单待实操。
- 工程细节新增：招标文件包为**多层嵌套 zip 且文件名 GBK 编码**；一包可对应多本技术规范书（按规范书 ID 与货物清单行关联）；商务与技术内容冲突裁决规则（技术参数以技术部分为准，交货期/资格/业绩/质保以商务部分为准，数量以货物清单为准）。
